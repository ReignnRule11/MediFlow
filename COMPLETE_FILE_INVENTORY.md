## 🚀 HOW TO USE

### 1. Frontend Setup
```bash
# Create frontend directory and copy files
mkdir -p mediflow-frontend/app lib components/auth components/patient styles
cp mediflow_frontend_package.json mediflow-frontend/package.json
cp mediflow_lib_*.ts mediflow-frontend/lib/
cp mediflow_components_*.tsx mediflow-frontend/components/
# ... copy other files ...
cd mediflow-frontend
npm install
npm run dev
```

### 2. Backend Setup
```bash
# Create backend directory and copy files
mkdir -p mediflow-backend/app/{core,models,routers,schemas} tests
cp mediflow_app_*.py mediflow-backend/app/
cp mediflow_tests_*.py mediflow-backend/tests/
# ... copy other files ...
cd mediflow-backend
pip install -r mediflow_backend_requirements.txt
uvicorn app.main:app --reload
```

### 3. Docker Setup (Recommended)
```bash

docker-compose up
```
